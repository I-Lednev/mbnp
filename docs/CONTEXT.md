# Контекст MBNP для новой сессии

Это краткая выжимка. Полная документация: `docs.html` на сайте и `docs/README.md` в репозитории.

## Проект

- MBNP (My Best NEWSpaper) — статический агрегатор новостей.
- Сайт: https://i-lednev.github.io/mbnp/
- Репозиторий: https://github.com/I-Lednev/mbnp
- GitHub Pages + GitHub Actions, без сервера и базы.

## Что уже сделано

- Разделы: Все, ИИ, Игры, Анонсы, Мобильные, Релизы, Слухи, Софт, Наука, Развлечения, Порты, ПК, Консоли, Железо, Индустрия, Обновления, ИИ-моды, ИИ-софт, Авто, Война, Избранное.
- Один источник Playground без деления на подразделы.
- Две даты на карточках, сортировка по появлению в агрегаторе.
- Сворачиваемое меню категорий, кнопка «Ещё».
- Переключатель крупных и компактных карточек на мобильном.
- Тематические SVG-заглушки для всех категорий.
- Вход по логину/паролю, приглашения, личный кабинет, размер сайта.
- Исправлено автозаполнение поиска логином.
- Раздел Reddit и пустые рассылки убраны.

## Где что лежит

- `index.html`, `styles.css`, `app.js` — сайт.
- `auth-config.js` — логин, соль, хэш пароля, версия приглашений.
- `access/config.json` — текущая версия приглашений.
- `scripts/fetch-news.mjs` — источники и сбор.
- `scripts/translate-news.mjs` — переводы.
- `data/` — данные.
- `docs.html`, `docs/README.md` — документация.

## Важные ограничения

- GitHub Pages не приватный: JSON доступны по прямым ссылкам.
- Репозиторий публичный.
- Полные тексты и переводы — риск по авторским правам.
- Reddit/Substack блокируют GitHub Actions.
- Расписание GitHub может задерживаться.

## Деплой

Git не установлен. Файлы заливаются через GitHub Contents API. После правок `app.js`/`styles.css` поднимать `?v=N` и `CACHE_NAME`.

## Если сломалось

1. Проверить Actions.
2. Запустить `update-news.yml` вручную.
3. Проверить `data/news.json` → `generatedAt`.
4. Проверить Pages и версии.
5. Проверить `auth-config.js` и `access/config.json`.
6. Проверить `max-bot.mjs` и лог.
