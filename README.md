# MBNP (My Best NEWSPaper)

Персональный агрегатор новостей: ИИ, игры, приставки и консоли, ИИ-моды и декомпиляции, ИИ-софт, автомобили и сводки по Украине. Одна страница, без сервера и без базы данных.

- **ИИ** — TechCrunch AI, The Verge AI, Habr AI, OpenAI News, Hugging Face, MIT Technology Review, WIRED AI, IEEE Spectrum AI
- **Игры** — StopGame, DTF, Игромания, 3DNews, IGN, Eurogamer, PC Gamer, VGC, Ars Technica Gaming
- **Приставки** — Nintendo Life, Nintendo Everything, Push Square, PlayStation Universe, Pure Xbox, Gematsu, Time Extension, SteamDeckHQ
- **ИИ-моды** — 80.lv, GamesIndustry.biz, Rock Paper Shotgun, GamesRadar+
- **ИИ-софт** — GitHub Blog, Stack Overflow, Hacker News, InfoQ AI/ML, Ars Technica Tech, BleepingComputer, Simon Willison
- **Авто** — Kolesa.ru, «За рулём», «5 колесо», Газета.Ru Авто, Motor1, Car and Driver, InsideEVs
- **Война** — Kyiv Independent, Ukrinform, Ukrainska Pravda, BBC Ukrainian, Radio Svoboda, Meduza, The Moscow Times, Novaya Gazeta Europe, The Guardian, UN News, Al Jazeera, The New York Times, BBC Russian, DW Russian

## Как это работает

```
GitHub Actions (каждые 30 минут)
        │
        ├─ fetch RSS/Atom          → data/news.json + data/digest/
        ├─ полный текст страниц     → data/articles.json
        └─ перевод через Google     → data/translations.json
        │
        ▼
   коммит в репозиторий  ──►  GitHub Pages  ──►  PWA на телефоне / в браузере
```

Сервер не нужен. GitHub Actions бесплатно собирает RSS-ленты, достаёт полный текст и фото со страниц, переводит новые материалы и коммитит готовые JSON. GitHub Pages раздаёт страницу и эти файлы. Браузер читает свой же JSON — никаких CORS-прокси и лимитов API.

## Что происходит автоматически

После первой настройки репозитория **ничего запускать вручную не нужно**. Каждые 30 минут GitHub Actions:

1. собирает свежие RSS-ленты в `data/news.json` и пополняет недельный дайджест в `data/digest/`;
2. достаёт полный текст и картинки со страниц статей в `data/articles.json` (до 60 новых страниц за запуск);
3. переводит новые материалы через Google Translate в `data/translations.json` (до 300 материалов за запуск);
4. коммитит изменения, а GitHub Pages сразу показывает новый выпуск.

Если сервис перевода или какой-то сайт недоступен, пайплайн не падает: читалка остаётся на RSS-анонсе, перевод догоняется следующим запуском. Вручную можно нажать **Actions → Обновить новости → Run workflow**, если хочется обновить прямо сейчас. Ваш компьютер для этого не нужен.

## Быстрый старт

Нужен Node.js 20+.

```bash
cd my-best-newspaper
npm.cmd install
node scripts/fetch-news.mjs
node scripts/enrich-articles.mjs
node scripts/translate-news.mjs
node scripts/serve.mjs
```

Откройте <http://localhost:5173>.

`npm.cmd` — для PowerShell, где обычный `npm` может блокироваться политикой выполнения. На macOS/Linux достаточно `npm install`. Зависимости нужны только для шага с полным текстом (`jsdom` + `@mozilla/readability`).

Локальная проверка перевода (в GitHub Actions это происходит автоматически):

```bash
# через Google, без ключа (так же делает GitHub Actions)
TRANSLATE_PROVIDER=google node scripts/translate-news.mjs

# если локально запущен Ollama
OLLAMA_MODEL=qwen3-coder:30b node scripts/translate-news.mjs

# или с бесплатным ключом DeepL
TRANSLATE_PROVIDER=deepl DEEPL_API_KEY=ваш_ключ node scripts/translate-news.mjs
```

Если в PowerShell разрешены npm-скрипты, можно короче:

```bash
npm.cmd run fetch
npm.cmd run enrich
npm.cmd run translate
npm.cmd run serve
```

> Важно: открывать `index.html` двойным щелчком нельзя — браузер не даст прочитать `data/news.json` с `file://`. Нужен локальный сервер.

- **9 разделов:** Все, ИИ, Игры, Приставки, ИИ-моды, ИИ-софт, Авто, Война, Избранное.
- **Выпуск за последние 7 дней:** новые материалы добавляются каждые 30 минут, старые не исчезают сразу — остаются в выпуске ещё 7 дней с полным текстом и переводом, просто опускаются ниже. Совсем старые уходят в дайджест.

- **Читалка внутри агрегатора:** клик по «Читать» открывает окно с заголовком, полным текстом статьи и всеми картинками. Текст сначала берётся из RSS, затем подтягивается со страницы источника через readability. Если сайт закрылся от ботов, остаётся RSS-анонс. Внизу — источник, «Скопировать ссылку» и «Открыть оригинал».
- **Перевод:** переключатель «Оригинал / По-русски» сверху. Переводятся заголовки, описания и текст читалки. Переводы кэшируются и обновляются только для новых или изменившихся материалов.
- **Чёрный список источников:** кнопка «Источники» открывает список. Снимите галочку — источник исчезнет из всех разделов. Вернуть можно там же одной галочкой или кнопкой «Показать все». Настройка хранится в `localStorage`.
- **Поиск** по заголовкам, описаниям и источникам, фильтр по источнику.
- **Недельный дайджест:** кнопка «Дайджест» открывает архив за последние 12 недель с фильтром по разделу.
- **Избранное** в `localStorage`.
- **Тёмная и светлая темы**, адаптивная вёрстка, PWA-установка и офлайн-кэш.
- **57 источников**; в выпуске за 7 дней обычно 300–500 материалов, до 600 в одном разделе.

## Дайджест и хранение

Текущий выпуск — это **последние 7 дней** (`NEWS_RETENTION_DAYS=7`). Новые материалы добавляются каждые 30 минут, но старые не выкидываются сразу: они остаются в выпуске с полным текстом и переводом, просто сортируются ниже по времени появления.

Когда материал старше 7 дней, он остаётся в недельном архиве `data/digest/YYYY-Www.json`:

- хранятся **12 последних недель** (`DIGEST_RETENTION_WEEKS`);
- в архиве только метаданные: заголовок, короткое описание, ссылка, источник, дата и обложка — без полного текста и без самих картинок;
- полный текст, переводы и галерея фото хранятся для текущего 7-дневного выпуска; старые выпуски открываются по ссылке на источник;
- кнопка **«Дайджест»** в строке состояния открывает архив: можно выбрать неделю и раздел.

По месту это экономно. Текущий выпуск на ~400 материалов занимает около 1 МБ, неделя дайджеста — 250–300 КБ; 12 недель — примерно 2–4 МБ. Вместе с `articles.json` и переводами проект остаётся в единицах-десятках мегабайт. Лимит GitHub Pages — 1 ГБ, так что места много. Картинки не скачиваются в репозиторий, а показываются с сайтов-источников.

## Читалка, полный текст и картинки

При открытии новости читалка сначала показывает RSS-текст, затем подгружает `data/articles.json`:

- если удалось скачать страницу — показывается основной текст, вырезанный через `@mozilla/readability`;
- если сайт отдаёт только анонс, блокирует ботов или требует JS — остаётся RSS-текст и заметка об этом;
- картинки собираются со страницы статьи и из RSS, до 20 штук: обложка сверху, остальные — сеткой ниже;
- RSS-текст хранится до 12 000 символов, полный текст со страницы — до 20 000.

`enrich-articles.mjs` обрабатывает до 60 новых страниц за запуск, кэширует результат по URL на 7 дней и не перезаписывает хороший старый текст ошибкой. Поэтому первый выпуск может догонять полные тексты несколько запусков, а дальше обновляются только новые материалы.

Кнопка «Открыть оригинал» всегда ведёт на статью. Некоторые издания платные или закрываются от ботов — для них полный текст останется на сайте.

## Перевод: автоматически через Google

По умолчанию ничего переводить вручную не нужно. Workflow в GitHub Actions сам запускает `scripts/translate-news.mjs` каждые 30 минут и использует **Google Translate без ключа** (`TRANSLATE_PROVIDER: google` в workflow). Новые материалы переводятся порциями до 300 штук за запуск, уже переведённые берутся из кэша. Если в текущем выпуске остались непереведённые карточки — это значит, что лимит запуска ещё не догнал их; следующая попытка через 30 минут.

Варианты провайдеров:

1. **Google Translate** — по умолчанию в Actions. Бесплатно, без ключа, но это неофициальный endpoint: возможны ограничения частоты. Если перевод не удался, приложение показывает оригинал, а следующая попытка будет через 30 минут.
2. **DeepL** — опционально, если хочется качества и стабильности. Бесплатный тариф — 500 тыс. знаков в месяц. Добавьте секрет `DEEPL_API_KEY` и поменяйте в workflow `TRANSLATE_PROVIDER: deepl`.
3. **Ollama локально** — только для проверки на своём компьютере. Модель задаётся через `OLLAMA_MODEL` (например, `qwen3-coder:30b`). В GitHub Actions её нет.

Переводы складываются в `data/translations.json`. Если перевод для карточки ещё не готов, она показывает оригинал и подсказку; после следующего обновления перевод появится сам. В читалке переводится заголовок, описание и первые ~1500 символов текста — полный текст на языке источника всегда доступен по кнопке «Открыть оригинал».

## Публикация на GitHub Pages

1. Создайте **публичный** репозиторий на GitHub, например `mbnp`.
2. Загрузите файлы проекта вместе с `package.json` и `package-lock.json` — workflow сам выполнит `npm ci`. Можно через веб-интерфейс: **Add file → Upload files**, либо через git:
   ```bash
   git init
   git add .
   git commit -m "init"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/mbnp.git
   git push -u origin main
   ```
3. В репозитории: **Settings → Pages → Build and deployment**.
   - Source: **Deploy from a branch**
   - Branch: **main**, папка **/ (root)**
4. Там же: **Settings → Actions → General → Workflow permissions** → **Read and write permissions** → Save.
5. Если хотите качественный автоперевод, добавьте **Settings → Secrets and variables → Actions → New repository secret** с именем `DEEPL_API_KEY`.
6. Откройте **Actions → Обновить новости → Run workflow**, чтобы сразу собрать первый выпуск.
7. Через минуту страница будет доступна:
   `https://ВАШ_ЛОГИН.github.io/mbnp/`

Дальше GitHub Actions сам обновляет новости и переводы каждые 30 минут.

### Свой домен

В **Settings → Pages → Custom domain** укажите домен и добавьте CNAME-запись у регистратора. HTTPS GitHub включит автоматически.

## Установка на телефон

Это PWA, отдельная сборка не нужна:

- **Android / Chrome:** меню ⋮ → «Установить приложение» (или «Добавить на главный экран»).
- **iPhone / Safari:** «Поделиться» → «На экран „Домой“».
- **Компьютер / Chrome, Edge:** иконка установки в адресной строке.

После установки появляется иконка, приложение открывается без адресной строки и работает офлайн с последним загруженным выпуском.

## Добавить или убрать источник

Откройте `scripts/fetch-news.mjs` и отредактируйте массив `FEEDS`:

```js
{
  id: 'my-source',          // уникальный ключ
  category: 'ai',           // ai | games | hardware | aimods | aisoft | cars | war
  name: 'Мой источник',     // подпись на карточке
  lang: 'ru',               // ru | en | uk
  url: 'https://example.com/rss.xml',
  // keywords: ['ai', 'нейросет'], // необязательно для общих лент
}
```

Проверьте локально:

```bash
node scripts/fetch-news.mjs
```

В консоли будет видно, сколько новостей дал каждый источник. Если лента отдаёт HTML вместо RSS, она попадёт в `errors` в `data/news.json` — такую ссылку лучше заменить.

## Что можно настроить

| Что | Где |
|---|---|
| Сколько новостей брать с одного источника | `MAX_PER_SOURCE` в `scripts/fetch-news.mjs` |
| Сколько хранить в одной категории | `MAX_PER_CATEGORY` в `scripts/fetch-news.mjs` |
| Сколько дней держать выпуск | `NEWS_RETENTION_DAYS` (по умолчанию 7) |
| Сколько карточек показывать сразу | `PAGE_SIZE` в `app.js` (по умолчанию 40) |
| Цвета и тема | переменные в начале `styles.css` |
| Расписание обновления | `cron` в `.github/workflows/update-news.yml` |
| Источники | `FEEDS` в `scripts/fetch-news.mjs` |
| Сколько недель хранить в дайджесте | `DIGEST_RETENTION_WEEKS` (по умолчанию 12) |
| Сколько статей дообогащать за запуск | `MAX_ENRICH` в workflow или env |
| Лимит времени на полные статьи | `ENRICH_TIME_LIMIT_MS` |
| Сколько дней кэшировать статьи | `CACHE_TTL_MS` в `scripts/enrich-articles.mjs` |
| Лимит перевода за запуск | `MAX_TRANSLATE_ITEMS` в workflow или env |
| Провайдер перевода | `TRANSLATE_PROVIDER` (`google`, `deepl`, `ollama`) |
| Модель Ollama | `OLLAMA_MODEL` |
| Ключ DeepL | секрет `DEEPL_API_KEY` |

## Ограничения

- **Задержка до 30 минут.** GitHub Actions может запускаться с опозданием в часы пик. Кнопка «Обновить» перечитывает уже собранный JSON, но не сами RSS.
- **Часть сайтов может блокировать IP GitHub Actions.** Если источник регулярно падает, замените его или добавьте резервный. Для упавших источников агрегатор старается сохранить прошлые новости.
- **Не все сайты отдают полный текст.** Readability хорошо работает на обычных статьях, но paywall, Cloudflare, JS-приложения и запрет ботов могут оставить только RSS-анонс. Это видно по заметке в читалке.
- **Полные тексты догоняются порциями.** За один запуск обрабатывается до 60 страниц; первый выпуск может наполняться несколько часов, дальше обновляются только новые материалы.
- **Картинки зависят от источника.** Мы собираем фото со страницы и из RSS, но если сайт отдаёт только обложку или блокирует загрузку, остальные останутся на сайте.
- **Украинские источники могут быть недоступны из РФ.** Сбор идёт на GitHub Actions, поэтому заголовки в агрегаторе появятся; для перехода на сайт может понадобиться VPN.
- **Бесплатные минуты Actions.** Для публичного репозитория стандартные раннеры бесплатны. Для приватного — 2000 минут/месяц.
- **Перевод не идеален.** Это машинный перевод; имена и термины иногда искажаются.

## Другие варианты хостинга

Те же файлы можно положить куда угодно:

- **Cloudflare Pages** — подключить репозиторий, build command оставить пустым, output directory `/`. Безлимитный трафик.
- **Netlify** — build command пустой, publish directory `.`. 100 ГБ/мес бесплатно.
- **Vercel Hobby** — статика, 100 ГБ/мес, только некоммерческое использование.

Сборка новостей и переводов всё равно остаётся на GitHub Actions, поэтому смена хостинга ничего не ломает.

## Идеи для развития

- Полнотекстовое извлечение статей с сайтов-источников (readability) и подгрузка всех фото со страницы.

- Фильтр по ключевым словам и персональные темы.

- Сортировка по источникам и «не показывать прочитанное».

```

│   ├── translations.json       # переводы (генерируется)

├── package.json
├── package-lock.json
└── .github/workflows/
    └── update-news.yml         # cron: сборка + статьи + перевод + коммит
```
