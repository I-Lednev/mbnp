MBNP — документация

My Best NEWSpaper. Всё, что нужно, чтобы понять проект и продолжить работу с другой сессии или компьютера.

Коротко. Статический новостной агрегатор на GitHub Pages. Данные собираются GitHub Actions и лежат в JSON. Сайт закрыт входом по логину и паролю, есть приглашения и личный кабинет. MAX-бот умеет показывать сводку и выполнять задачи через OpenCode.

2. Архитектура

  • GitHub Pages — раздаёт HTML, CSS, JS и JSON. Сервера и базы данных нет.
  • GitHub Actions — каждые 30 минут собирает RSS, переводит и коммитит данные.
  • Данные — data/news.json, data/translations.json, data/articles.json, data/digest/.
  • Вход — клиентская проверка пароля по PBKDF2-хэшу, сессия в localStorage.
  • Приглашения — ссылка с версией; отзыв всех приглашений меняет версию в access/config.json.
  • MAX-бот — отдельный Node.js-процесс на ПК, long polling MAX Bot API.

4. Как обновляются новости

Основной путь — GitHub Actions:

  1. update-news.yml запускается по расписанию, вручную или после изменения скриптов.
  2. Собирает RSS в news.json.
  3. Достаёт полные тексты в articles.json.
  4. Переводит новые материалы в translations.json.
  5. Коммитит данные, GitHub Pages пересобирает сайт.

Расписание GitHub работает не строго по часам: запуски могут задерживаться и иногда пропускаться. Для ручного запуска:

gh workflow run update-news.yml -R I-Lednev/mbnp --ref main
Важно. Раньше на ПК была задача «MBNP Update» — она запускала сборку каждые 30 минут. Если сайт должен обновляться без ПК, эту задачу нужно отключить, а полагаться на GitHub Actions и workflow «Плановый запуск».

5. Деплой вручную

Git не установлен. Файлы заливаются через GitHub Contents API. Пример на Node.js:

const api = 'https://api.github.com';
const headers = {
  authorization: `Bearer ${process.env.GH_TOKEN}`,
  accept: 'application/vnd.github+json',
  'x-github-api-version': '2022-11-28',
  'user-agent': 'MBNP-Deploy',
  'content-type': 'application/json',
};

const file = 'index.html';
const bytes = await readFile(file);
const current = await (await fetch(`${api}/repos/I-Lednev/mbnp/contents/${file}`, { headers })).json();
await fetch(`${api}/repos/I-Lednev/mbnp/contents/${file}`, {
  method: 'PUT',
  headers,
  body: JSON.stringify({
    message: `deploy: ${file}`,
    content: bytes.toString('base64'),
    sha: current.sha,
    branch: 'main',
  }),
});

После изменения app.js или styles.css поднимайте версию в index.html (?v=N) и CACHE_NAME в sw.js, иначе браузер отдаст старую версию из кэша.

6. Вход, приглашения и кабинет

  • Пароль хранится только как PBKDF2-хэш в auth-config.js. Открытого пароля в коде нет.
  • Сессия живёт 30 дней в localStorage.
  • Приглашение — ссылка #invite=vN.код. Версия сверяется с access/config.json.
  • Кнопка «Аннулировать все» увеличивает версию в access/config.json; старые ссылки перестают работать.
  • Для отзыва нужен GitHub fine-grained token с правом Contents: Read and write. Токен хранится только в браузере.
  • «Размер сайта» в кабинете считает файлы через GitHub API.

Сменить пароль

node scripts/make-password-hash.mjs "новый пароль"

Полученные salt и hash вставьте в auth-config.js и задеплойте файл.

8. Источники и категории

Источники описаны массивом FEEDS в scripts/fetch-news.mjs. Чтобы добавить источник, добавьте объект:

{ id: 'example', category: 'games', name: 'Example', lang: 'en', url: 'https://example.com/feed' }
  • keywords — фильтр для общих лент.
  • type: 'github' — поиск репозиториев GitHub.
  • type: 'substack' — Substack API.
  • type: 'reddit' — Reddit OAuth (нужны ключи).

Категории: ИИ, Игры, Анонсы, Мобильные, Релизы, Слухи, Софт, Наука, Развлечения, Порты, ПК, Консоли, Железо, Индустрия, Обновления, ИИ-моды, ИИ-софт, Авто, Война.

9. Переводы

translate-news.mjs переводит заголовки, анонсы и текст. По умолчанию Google Translate, до 300 материалов за запуск. Для рассылок лимит текста увеличен до 12 000 символов и разбивается на части.

Провайдеры: Google, DeepL (ключ), Ollama (локально). Настройки — переменные окружения в workflow.

10. Дайджест

Архив за 12 недель лежит в data/digest/YYYY-Www.json, открывается кнопкой «Дайджест». Внутри — метаданные и ссылки, полный текст остаётся в источниках.

11. Ограничения и риски

  • GitHub Pages не умеет делать сайт приватным. Вход скрывает интерфейс, но JSON доступны по прямым ссылкам.
  • Репозиторий публичный: код и данные видны на GitHub.
  • Полные тексты статей и переводы — риск по авторским правам. Безопаснее заголовок + короткий анонс + ссылка.
  • Reddit блокирует датацентры (429), Substack — 403. Для них нужны API-ключи или прокси.
  • GitHub Actions может задерживать и пропускать расписание.

12. Если что-то сломалось

  1. Откройте Actions и проверьте последний запуск.
  2. Запустите вручную: gh workflow run update-news.yml -R I-Lednev/mbnp --ref main.
  3. Проверьте data/news.json и generatedAt.
  4. Если сайт не обновился — проверьте сборку Pages и версии ?v= / CACHE_NAME.
  5. Если не работает вход — проверьте auth-config.js и access/config.json.
  6. Если молчит MAX-бот — проверьте процесс max-bot.mjs и лог max-bot.log.
